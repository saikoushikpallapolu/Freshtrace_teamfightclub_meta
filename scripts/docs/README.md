# Product plan PDF source

build_product_build_plan.py generates docs/product_build_plan.pdf from the repository root. Use Python with reportlab and the Segoe UI fonts in C:/Windows/Fonts (Windows authoring environment). Run: python scripts/docs/build_product_build_plan.py. The generator changes documentation only; render and inspect the PDF after editing it.

See [repository architecture](../../docs/repository_architecture.md) for the complete layout and implementation boundaries.
