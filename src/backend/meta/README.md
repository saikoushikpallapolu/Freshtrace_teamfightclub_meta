# Hosted Meta adapters

Planned files: client.py, segmentation.py, vision.py, planner.py and optional transcription.py. Centralize server-only credentials, bounded retries, usage and response IDs. SAM returns parsed geometry, Spark returns evidence observations and Wonder proposes allowlisted tools. No live integration is implemented here.
